# Exercise 04: Blinking LEDs with millis()

This exercise demonstrates how to blink multiple LEDs independently using the `millis()` function for non-blocking timing on an ESP32.

## Components

- ESP32 DevKit V1
- 3x LEDs
- 3x 220 Ω resistors
- Jumper wires
- Breadboard

## Concepts

- Non-blocking timing
- millis() function
- Independent LED control
