# Exercise 01: Blinking an LED

This exercise demonstrates four different ways to blink an LED using an ESP32.

## Methods 

1. Using delay().
2. Using a state variable and delay().
3. Using digitalRead() and delay().
4. Using millis() for non-blocking timing.

## Components

- ESP32 DevKit V1
- LED
- 220 Ω Resistor
- Jumper wires
- Breadboard
