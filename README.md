# ESP32 Lab

A hands-on repository for learning embedded systems development using the ESP32 microcontroller.

## Purpose

This repository documents my learning journey through practical exercises and small projects, exploring fundamental concepts of embedded systems, electronics, and microcontroller programming.

## Hardware & Technologies

- ESP32 DevKit V1
- C/C++
- Arduino Framework
- Arduino IDE

## Topics

- GPIO and digital I/O
- Timers and non-blocking programming
- Buttons, interrupts, and debouncing
- Sensors and actuators
- PWM and ADC
- Wi-Fi and Bluetooth communication

## Status

Work in progress. New exercises and projects will be added as I continue learning.
